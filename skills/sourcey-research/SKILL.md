# Sourcey research

Use this skill when a user wants to find or compare startup offers, inspect the evidence behind one, or understand an Agent Readiness report card.

1. Search the relevant Sourcey records with the hosted MCP, then open the record or evidence before recommending it. For comparisons, inspect each candidate's source and terms.
2. Separate sourced facts from Sourcey's analysis. State the recorded freshness and any eligibility unknowns; do not turn a missing condition into a guarantee.
3. For Agent Readiness, report the visible method, coverage, findings and blockers. A prepared declaration is input for review, not a new verified grade.
4. The hosted MCP reads Sourcey data and prepares declarations. Sourcey's documentation generator and paid HTTP services are separate surfaces; do not claim this connection performed either.

Use [Sourcey's MCP guide](https://sourcey.com/mcp) when the current tool schema or setup differs from an example.
