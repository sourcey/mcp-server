# Sourcey

![Sourcey mark](.claude-plugin/icon.png)

Find evidence-backed startup offers and inspect Agent Readiness reports with Sourcey's hosted MCP connection and research skill. Search for credits, discounts, free tiers and programs, then inspect the original sources, recorded terms, freshness and eligibility unknowns before choosing an offer.

For Agent Readiness, examine each report's method, coverage, findings, blockers and supporting evidence. The connection can prepare a declaration for review; it does not assign a new verified grade.

## Connection and privacy

This plugin connects directly to [Sourcey's public HTTPS MCP server](https://mcp.sourcey.com/mcp). It needs no API key, local credentials, package installation, wallet or background process. Queries and record references deliberately sent to the server are transmitted to Sourcey under its [privacy policy](https://sourcey.com/privacy).

The plugin includes the Sourcey research skill. It does not run Sourcey's documentation generator or make purchases through the separate paid HTTP API. Sourcey has been one project since 2016; this plugin exposes its current research services.

## Try it

- Find three current cloud-hosting startup offers. Show the original source, last-checked date and eligibility unknowns for each.
- Compare two offers using their recorded terms and evidence. Separate confirmed conditions from conditions that remain unverified.
- Find an Agent Readiness report and explain its tested workflows, blockers and unverified claims.

See the [MCP guide](https://sourcey.com/mcp), [Sourcey website](https://sourcey.com), [support](https://sourcey.com/support) and [terms](https://sourcey.com/terms). The plugin files are MIT licensed.
